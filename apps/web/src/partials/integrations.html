Connect WooCommerce

Uses WooCommerce core REST API v3. Start with a read-only key.

In WordPress: WooCommerce → Settings → Advanced → REST API → Add key. Read access is enough for polling; read/write is needed only if PennyWise Accounting registers webhooks for you.

Connect Etsy

Secure OAuth requests only shop and transaction read access.

Etsy redirects back to this browser after authorization. Access tokens are encrypted and refreshed automatically. Buyer email access is not requested.
