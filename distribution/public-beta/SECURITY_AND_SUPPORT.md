# ClearLedger Public Beta Security and Support

Verify the ZIP SHA-256 against the value on the official ClearLedger download page
before extracting it. Keep the default `127.0.0.1:3000` binding, do not publish the API
port, use a supported and patched browser/Docker host, and protect access to Docker,
backups, and the Windows account that runs the beta.

For an ordinary defect, use **Help > Report a bug** inside ClearLedger. Download the
privacy-safe support details, reproduce the issue with fictional data where possible,
and use the current support path published at
<https://typewritingmonkeys.com/clearledger-support/>. A report is not sent until the
operator deliberately copies or sends it.

For a suspected security vulnerability, do not include live credentials, private
business records, exploit payloads against other systems, or customer data in a public
post. Use the private security-reporting instructions on the same official support
page. Include the ClearLedger version, package SHA-256, affected workflow, impact,
reproduction steps, and a minimal sanitized proof. Preserve logs and request IDs.

This free beta has no guaranteed service level, recovery time, security bounty, or
accounting-support commitment. If a problem could affect filings, payments, balances,
inventory, access control, or data integrity, stop the affected workflow, preserve a
backup and source evidence, and seek appropriate professional review before continuing.
