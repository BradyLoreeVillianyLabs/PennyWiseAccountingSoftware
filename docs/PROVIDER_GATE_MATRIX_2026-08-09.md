# Provider Gate Matrix — 2026-08-09

**Purpose:** a commercialization control for the controlled beta. It records what may be
represented or enabled now versus what needs provider-specific acceptance evidence. It is
not a provider approval, contract, or certification.

## Current commercial boundary

The supported offer is a verified local/controlled-share beta with paid assisted onboarding.
Manual beta provisioning may occur only after confirmed payment through the authorized
commercial endpoint. Do not grant an entitlement from a browser request, sell automated
subscriptions, or represent the package as a hosted automated accounting service while the
applicable gates remain open.

`REVIEW/SHADOW` means a connector may stage evidence for human review but cannot create
ledger entries. `GATED` means the capability must stay unavailable for production or broad
commercial use until all listed evidence is accepted and recorded.

## Gate execution rule

For every external provider, retain an owner-approved record of the approved test account,
minimum scopes, contract/terms, rate-limit plan, retention decision, signature verification,
failure/retry test, and reconciled live fixture. Refresh the threat model before a provider
integration changes. If any required evidence is absent, retain the current default-deny,
review/shadow, or manual boundary; a client-side flag must never unlock live posting.
