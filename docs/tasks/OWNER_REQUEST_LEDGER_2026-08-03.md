but is not a release claim until the final merged tests pass. `Active` means work is in
the current merge. `External gate` means the requirement remains open but cannot be
honestly completed with code alone. `Boundary retained` records a deliberate safety or
scope decision, not a dropped request.

1. verified and included;
2. explicitly excluded from the beta with a usable manual/native alternative;

   professional action still required.
